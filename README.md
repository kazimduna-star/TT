# Лунные равнины — VRM Edition (версия для GitHub)

Игра разобрана на части: каждый файл меньше 25 МБ, поэтому грузится через браузер GitHub.
Общий вес проекта около 85 МБ (меньше 110 МБ).

## 12 файлов, все в корень репозитория, имена ровно такие:
index.html, style.css, main.js, world.js, animator.js,
p0a.bin, p0b.bin, p1.bin, p2.bin, music.bin, README.md

(p0a.bin + p0b.bin — две половинки первой модели, игра склеивает их сама.)

## Запуск
1. Создай НОВЫЙ репозиторий (старые файлы с цифрами в названиях не мешают).
2. Add file → Upload files. Загружай в 2-3 захода: сначала код (5 файлов), потом p0a, p0b, p1, p2, music.
3. Проверь, что имена без пробелов и цифр вроде "main 2.js".
4. Settings → Pages → Deploy from a branch → main → /(root) → Save.
5. Открой ссылку из раздела Pages (https://НИК.github.io/ИМЯ/).

## Управление
WASD бег, Shift ускорение, Пробел прыжок, J/F удар, E лунная волна, мышь (зажать) камера.
На телефоне: джойстик слева, кнопки справа.
